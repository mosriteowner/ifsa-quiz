# IFSAクイズ JSONデータ

「改正・遺体衛生保全自主基準」に関する自主作成クイズの問題データです。

- 章別JSON: quiz_ch1.json 〜 quiz_ch8.json
- 前文・見出し: ifsa_headings.json, quiz_preamble_8.json
- 簡易閲覧ページ: https://mosriteowner.github.io/ifsa-quiz/ （GitHub Pages）

クイズ形式で学べるように作っています。ご自由にご利用ください（教育・学習目的に限る）。

**重要：出典・著作権について**  
本クイズは、一般社団法人日本遺体衛生保全協会（IFSA）が発行する書籍  
『遺体衛生保全概論』（2012年刊、佐藤喜宣監修代表）  
に掲載された「改正・遺体衛生保全自主基準」（2010年改正版）を参考・基に作成した学習用クイズです。  

元の基準全文は上記書籍でご確認ください（国立国会図書館などで閲覧可能です）。  
著作権はIFSAに帰属します。本クイズは教育・啓発目的の非営利利用に限り、商用利用を禁じます。  
IFSAまたは権利者より削除・修正等の要請があった場合には、即時対応いたします。
